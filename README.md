# 🎭 Playwright E2E Tests - OrangeHRM

Este repositório contém uma suíte de testes automatizados End-to-End (E2E) desenvolvida com **Playwright** e **JavaScript**, focada em validar os fluxos críticos da aplicação corporativa de RH **OrangeHRM**.

---

## Objetivo do Projeto

Demonstrar a aplicação de boas práticas em automação de testes utilizando o Playwright para validar funcionalidades de um sistema empresarial real, garantindo resiliência, velocidade e autonomia nos cenários de teste.

---

## Tecnologias Utilizadas

* **[Playwright](https://playwright.dev/)** — Framework de automação E2E
* **JavaScript** — Linguagem de programação
* **Node.js** — Ambiente de execução
* **Git & GitHub** — Versionamento de código

---

## Cenários de Teste Cobertos

1. **Autenticação:**
   * Login realizado com sucesso no sistema.
   * Redirecionamento correto para o Dashboard.
   * Logout seguro da aplicação.

2. **Gestão de Colaboradores (Módulo PIM):**
   * Cadastro de novos funcionários no sistema.
   * Validação de criação do perfil do colaborador.
